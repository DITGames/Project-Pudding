# Project-Pudding

コインプッシャーとコマンドバトルを融合したプロトタイプゲーム（Unity 6 / URP）。

プッシャー台にコインを投げ込み、押し出して落としたコインが**バトルの行動リソース**に変換される。プレイヤーは物理挙動のプッシャーでリソースを稼ぎながら、リアルタイムに進行するコマンドバトルでスキルを撃ち、敵パーティを全滅させれば勝利。

## ゲームの流れ

1. **コイン投入** — 画面左右の投入口からコインを投げ込む。台は周期的に前後へ動き、堆積したコインを押し出す
2. **リソース変換** — 手前に落ちたコインは回収されてバトルリソースに加算される（変換レート補正あり）。奥や横に落ちた分は消滅
3. **コマンド入力** — リソースが溜まりスキルが撃てる状態になったら、コマンド入力を開いてユニット → コマンド → スキル → ターゲットの順に選択
4. **バトル進行** — バトルは一定間隔のティックで進行。敵は自動でリソースを獲得し、AI が状況判断して攻撃・回復・サポートを仕掛けてくる
5. **決着** — 相手パーティの全滅で勝敗が決まる

## 操作

| 入力 | 動作 |
|---|---|
| ← / → | 左右の投入口からコインを投げる |
| C / ゲームパッド△ | コマンド入力を開く（発動可能なスキルがあるときのみ） |
| クリック / 決定 | ユニット・コマンド・スキル・ターゲットの選択 |
| キャンセル / 戻るボタン | 選択を1段階戻す |

## バトルシステム

### リソースと属性

リソースは **ノーマル / 火 / 水 / 土 / 光 / 闇** の6種。落としたコインの種類に応じたプールに加算され、スキルはそれぞれ消費リソースを持つ。ユニットとスキルにも属性があり、弱点属性は 1.5 倍、耐性属性は 0.75 倍のダメージ補正がかかる。

### スキル

スキルは攻撃 / 回復 / サポート / スペシャルのロールを持ち、以下のパラメータで制御される。

- 消費リソース（属性別コスト）
- クールタイム・1バトル中の最大使用回数
- ターゲット範囲（単体敵 / 全体敵 / 単体味方 / 全体味方 / ランダム / 自身）
- 付与エフェクト（対象または自身にバフ・状態異常を付与）

### ステータスエフェクト

毒などの状態異常、攻撃力バフ等のパラメータ補正をエフェクトとして付与できる。スタック方針・持続条件・行動制限（行動不可など）を個別に定義可能。

### 敵パーティAI

敵は「性格プロファイル」で駆動されるパーティ単位の AI。

- **積極性・警戒度・知能** の3性能値で行動傾向が変わる
- 知能が低いほど行動選択にノイズが乗り、最適手を外す
- リソースの増加ペースを観測し、「今撃つか、溜めて大技を待つか」を判断する
- 「敵残り1体」「HP 50% 以上」などの条件を組み合わせた**シチュエーションルール**で、状況ごとに攻撃・回復・サポートの優先度が切り替わる

プロファイルと条件はすべて ScriptableObject アセット（`Assets/GameData/AI/`）で、コードを書かずに調整できる。

- Unity **6000.3.17f1**
- Universal Render Pipeline 17.3.0

## 開発者向け

コード構成・アーキテクチャ・コーディング規約は [CLAUDE.md](./CLAUDE.md) を参照。

- `Assets/Scripts/CommandBattleCore/` — 汎用コマンドバトルエンジン

- `Window > Custom Console` / `Window > Recent Assets` — 開発用エディタ拡張
